# 여행노트

비밀번호로 열고, 여행과 날짜별 일정을 직접 입력하는 웹페이지입니다.

**사이트:** https://namyikim.github.io/travel_plan/ (GitHub Pages 배포 후 접속)

- 여행명·목적지·여행 기간·동행 인원 입력
- 날짜별 시간·장소·이동·숙소·메모·예약 링크 관리
- 장소 지도 검색, 여행 및 일정 수정·삭제
- 모바일·PC에서 같은 비공개 기록 조회
- 비밀번호 잠금, 연결 정보 자동 등록, 암호화 백업

## 처음 연결하기

처음 한 번만 설정합니다. **사이트를 올리는 토큰과 여행 데이터를 저장하는 토큰은 별개**입니다.

1. 데이터 저장 위치는 개인용 **`namyikim/travel-data`**로 고정되어 있습니다. 사용자 이름·저장소 이름을 사이트에 입력할 필요가 없습니다. 이 저장소가 없다면 GitHub에서 `travel-data`라는 이름으로 **비공개(Private)** 저장소를 만들고 README를 추가하세요.
2. [Fine-grained token 설정](https://github.com/settings/personal-access-tokens/new)에서 **`travel_plan`과 `travel-data` 두 저장소**를 선택하고 **Contents → Read and write** 권한을 부여합니다. 기존 토큰에 두 저장소가 포함되어 있다면 그대로 사용합니다.
3. 사이트의 **최초 1회 · 비밀번호 설정**에서 토큰과 **8자 이상 비밀번호**를 입력합니다. 비밀번호를 잊으면 암호화한 기록을 복구할 수 없습니다.
4. **비밀번호 설정하고 시작하기**를 누르면 암호화된 연결 정보가 자동 등록됩니다. 파일 다운로드나 GitHub 수동 업로드가 필요 없습니다.
5. 다른 휴대폰·PC에서는 사이트를 열고 **같은 비밀번호만 입력**하세요. 등록 직후 반영이 지연되면 잠시 후 다시 시도합니다.

자동 등록을 위해 토큰은 두 저장소에 접근해야 합니다. 등록 실패 시 현재 탭은 유지되며 **연결 설정 → 비밀번호 접속 다시 등록**으로 재시도할 수 있습니다. 토큰을 교체해야 한다면 로그아웃한 뒤 최초 설정에서 새 토큰과 기존 비밀번호를 입력하세요.

여행 정보나 토큰 원문을 공개 저장소에 업로드하지 마세요. 이 프로젝트에는 기본 비밀번호나 개인 토큰이 포함되어 있지 않습니다. 개인용 설정이며 회원가입이나 다른 사용자의 저장소 입력은 제공하지 않습니다. 기존에 업로드한 암호화 연결 파일도 계속 읽을 수 있습니다.

## 사용법

1. 비밀번호로 여행노트를 엽니다.
2. **새 여행**을 눌러 목적지와 기간을 입력합니다.
3. 날짜를 선택하고 **일정 추가**로 시간·장소·숙소·참고 링크를 적습니다.
4. 편집 창의 **반영**을 누르면 서버에 자동 저장됩니다. 여행·일정·체류 기간의 수정과 삭제, 지도 위치 선택도 자동 저장됩니다. 실패하면 입력 내용을 유지하고 **저장 다시 시도** 버튼을 표시합니다. 저장 중에는 중복 편집을 막으며, 충돌 시 기존 기록을 덮어쓰지 않습니다.
5. **잠그기** 또는 페이지 새로고침 후에는 다시 비밀번호를 입력합니다.

시간은 여행지의 현지 시각을 그대로 적습니다. 자동 시차 변환은 하지 않습니다. 지도 버튼은 목적지와 장소로 Google 지도를 검색합니다.

### 날짜별 지도와 동선

달력 아래 **일정 / 지도에서 보기** 탭을 선택합니다. 지도는 선택한 현지 날짜의 일정만 시차를 반영한 순서로 표시합니다. 최초에는 각 일정에서 정확한 장소명·주소로 **장소 검색** 후 결과를 선택하거나 **지도에서 지정**으로 직접 위치를 선택하세요. 선택한 위치는 여행 데이터와 함께 자동으로 암호화 저장됩니다. 일정 제목을 바꾸면 잘못된 위치를 유지하지 않도록 해당 위치를 다시 지정해야 합니다.

번호 마커와 파란 점선은 방문 순서를 나타내며 실제 도로·항공 경로가 아닙니다. 위치가 없는 일정은 연결선에서 건너뛰어 이어 붙이지 않습니다. 모든 위치를 지정한 뒤 **자동차 경로**를 누르면 OSRM의 도로 경로·거리·이동 예상 시간을 표시합니다(교통·체류 시간 제외). 비행기·배 일정이나 섬 사이 이동은 자동차 경로가 제공되지 않을 수 있습니다. 장소 목록의 **다음 장소 길찾기**는 Google Maps를 엽니다. 방문 순서는 입력한 일정 순서를 유지하며 자동 최적화하지 않습니다.

지도는 Leaflet 1.9.4 (`vendor/leaflet/LICENSE`)와 OpenStreetMap을 사용합니다. 검색 버튼을 누를 때만 검색어를 Nominatim에 전송하며 자동완성·일괄 검색은 하지 않습니다. 검색은 1.1초 이상 간격으로 제한하고 탭 메모리에 결과를 재사용합니다. 자동차 경로 버튼은 좌표를 OSRM 공개 서비스에 전송합니다. 외부 서비스 장애·검색 누락 시 직접 위치 지정과 Google Maps 링크를 사용할 수 있습니다. 개인정보가 담긴 예약 메모·토큰·비밀번호는 지도 서비스에 전송하지 않습니다.

### 여행 달력 요약

여행을 선택하면 월별 달력에 기존 일정이 아이콘과 짧은 제목으로 표시됩니다. 달력 날짜를 누르면 그날의 상세 일정으로 이동합니다. 일정이 많으면 처음 3개와 추가 개수를 표시하며, 월 이동 버튼으로 여행 기간의 다른 달을 확인할 수 있습니다. 달력은 각 일정에 입력한 현지 날짜 기준입니다.

**지역·체류 기간**에서 오아후·마우이 같은 지역명과 시작일·종료일을 등록하면 해당 날짜들을 가로지르는 연속 막대로 지역을 표시합니다. 같은 지역의 이어지는 기간은 화면에서 연결하며, 주·월이 바뀌면 이어짐 표시와 함께 다음 줄로 표시합니다. 이동일에는 두 지역의 기간이 겹쳐도 됩니다. 등록된 지역 버튼을 눌러 수정·삭제할 수 있습니다. 기존 일정의 아이콘은 내용에서 자동 선택하며, 일정 수정의 **달력 아이콘**으로 직접 지정할 수 있습니다. 체류 기간과 아이콘은 반영 버튼을 누르면 자동 저장됩니다.

### 한국·미국 시간 입력

일정의 날짜와 시간은 선택한 지역의 현지 시간으로 입력합니다. 한국·하와이·미국 서부/산악/중부/동부·알래스카·피닉스를 지원하며 서머타임을 자동 반영합니다. 예를 들어 11일 22:00 한국 출발, 11일 10:00 하와이 도착은 출발 다음 도착 순으로 표시합니다. 날짜별 화면은 현지 날짜로 묶고, **전체 여행을 실제 시간순으로 보기**를 켜면 날짜가 달라도 실제 시간순으로 확인할 수 있습니다. 시간이 없는 일정은 마지막에 표시합니다. 서머타임 종료로 같은 시간이 두 번이면 기본은 첫 번째이며 입력창에서 두 번째로 변경할 수 있습니다. 기존 일정은 한국 시간으로 유지되므로 미국 일정은 수정창에서 시간대를 선택해 주세요.

### 금액 입력

일정 추가·수정 창에서 USD와 원화(KRW)를 각각 입력합니다. USD는 소수점 두 자리, 원화는 정수이며 입력하지 않아도 됩니다. 동일 지출의 환산액을 양쪽에 중복 입력하지 마세요. 일정 카드와 여행 전체 합계에 통화별 금액을 표시합니다. USD는 센트 정수, 원화는 원 단위로 따로 저장하여 향후 환율 합산에 사용할 수 있습니다. 현재 합계는 환율을 적용하지 않습니다.

### 저장과 충돌

기록은 비공개 저장소의 `travel-data.json`에 **암호화되어** 저장됩니다. 여행 기록은 브라우저에 영구 저장하지 않습니다. 로그인하면 이 브라우저의 IndexedDB에 기기용 암호화 키와 암호화된 접속 정보를 보관하여 재접속 시 자동 로그인합니다. 비밀번호와 토큰은 평문으로 저장하지 않습니다. 로그아웃하면 저장된 접속 정보를 삭제합니다. 공용 기기에서는 사용 후 로그아웃하세요. 브라우저 데이터 삭제·시크릿 모드·다른 브라우저에서는 다시 로그인해야 합니다. 인터넷이 끊기거나 저장이 실패해도 현재 탭에는 입력이 남지만, 페이지를 닫으면 저장하지 않은 내용은 없어집니다.

다른 기기가 먼저 저장하면 자동 덮어쓰지 않고 충돌을 알립니다. 현재 변경을 보관하려면 **연결 설정 → 암호화 백업 내려받기**를 이용한 뒤 **새로 불러오기**로 최신 내용을 확인하세요. 자동 병합은 지원하지 않습니다.

### 비밀번호·토큰 변경

- **비밀번호:** 연결 설정에서 새 비밀번호를 입력하면 현재 기록과 연결 정보가 자동으로 갱신됩니다. 다른 기기에서도 새 비밀번호로 열 수 있습니다. 데이터 저장 후 연결 정보 갱신에 실패하면 현재 탭에서 **비밀번호 접속 다시 등록**을 누르세요. 탭을 닫았다면 최초 설정에서 토큰과 새 비밀번호로 다시 연결하세요.
- **토큰 만료/교체:** 잠금 화면의 최초 설정에서 두 저장소에 권한이 있는 새 토큰과 기존 비밀번호로 연결하면 접속 정보가 자동 갱신됩니다.
- **백업 복구:** 암호화 백업을 비공개 데이터 저장소의 `travel-data.json`으로 교체한 뒤 그 백업에 사용한 비밀번호로 연결합니다. 현재 파일을 먼저 백업하고 복구하세요. 자동 가져오기 화면은 없습니다.
- 과거 Git 커밋의 암호문은 그대로 남습니다. 비밀번호 변경은 이미 공유된 과거 데이터·토큰의 접근 권한을 소급 철회하지 않습니다. 이전 토큰의 접근을 막으려면 GitHub에서 토큰을 폐기·교체해야 합니다.

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment**에서 다음과 같이 설정합니다.

- Source: **Deploy from a branch**
- Branch: **main** / **/(root)**
- Save 후 Pages 배포 완료를 기다립니다.

별도 빌드나 서버는 필요하지 않습니다. Pages 설정에는 저장소 관리 권한이 필요할 수 있습니다. 코드 푸시 권한만으로 Pages 설정을 변경하지 못할 수도 있습니다.

## 구조 및 검증

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 한국어 반응형 화면과 입력 처리 |
| `core.js` | 날짜·링크·데이터 검증과 여행·일정 CRUD |
| `crypto.js` | PBKDF2-SHA256 600,000회, AES-256-GCM 암호화 |
| `sync.js` | 비공개 기록 동기화, 암호화 연결 자동 등록, SHA 충돌 감지 |
| `session.js` | 메모리 세션, 잠금, 저장·재조회·비밀번호 변경 |
| `tests/` | 데이터·암호화·세션·API·HTML 계약 테스트 |

Node.js 22 이상에서 실행합니다. 런타임 및 테스트 패키지 설치가 필요 없습니다.

현재 배포 토큰에 Workflows 쓰기 권한이 없어 GitHub Actions 자동 테스트 설정은 포함하지 않았습니다. 아래 명령으로 같은 테스트를 실행할 수 있습니다.

```bash
npm test
```

정적 서버에서 미리 볼 수 있습니다. 암호화는 **HTTPS 또는 localhost**가 필요합니다. 연결 정보는 공개 저장소의 암호문을 인증 없이 읽은 뒤 브라우저에서 비밀번호로 해제합니다. 토큰 원문과 여행 내용은 공개하지 않습니다.

```bash
python3 -m http.server 8000
```

보호 범위는 암호화된 연결·여행 데이터입니다. 공개 사이트 자체의 HTML·JavaScript는 누구나 볼 수 있습니다. 잠금 해제 중인 기기나 악성 브라우저 확장 기능에 대한 보호를 보장하지 않습니다.

### 하와이 테마

여행명·목적지·체류 지역에 하와이, 오아후, 마우이 등이 있으면 해변 배경과 섬 테마를 자동 적용합니다. 일정 내용과 금액은 흰색 카드 위에 표시합니다. `assets/hawaii-coast.png`는 내장 이미지 생성 도구로 만든 장식용 이미지이며 실제 특정 장소의 사진이 아닙니다. 생성 프롬프트: 하와이 가족 여행 사이트의 넓은 파노라마 배경, 푸른 태평양과 백사장, 화산 능선, 오른쪽 위 야자수, 파란색 UI와 어울리는 아침빛, 왼쪽 제목 공간, 글자·로고·사람 없음.


### 날짜별 지도에서 이동시간 표시

'지도에서 보기' 탭에서는 각 날짜의 **1 → 2, 2 → 3** 등 지점 사이에 예상 이동시간을 분 단위로 입력할 수 있습니다. 입력 후 다른 칸으로 이동하면 기존 일정 자동저장 방식을 통해 암호화된 여행 데이터에 반영됩니다. 지도 위치가 있는 연속 두 지점에는 연결선 위에 **약 45분**, **약 1시간 20분**처럼 배지가 나타납니다. 값이 없다면 배지는 표시되지 않습니다.

입력한 시간은 사용자 계획값으로, 자동차 경로 검색(OSRM)이 반환하는 자동 예상 시간과 다릅니다. 지점 순서가 바뀌면 예전 구간 시간이 새 출발지에 잘못 연결되지 않도록 출발 지점 ID를 함께 저장합니다. 기존 version 1 여행 데이터는 그대로 읽을 수 있으며, 시간 정보를 지우려면 입력란을 비우면 됩니다.

### 섬별 맛집
왼쪽 **맛집**에서 오하우·마우이·빅아일랜드 탭을 선택하고 직접 맛집을 등록할 수 있습니다. 이름, 위치·주소, 추천 메뉴, 지도·예약 링크, 메모를 입력하고 **맛집 반영**을 누르면 자동 저장됩니다. 수정·삭제와 지도 검색을 지원하며, 목록은 개별 여행과 독립적으로 기존 비공개 데이터에 함께 암호화되어 저장됩니다.

각 섬 탭에는 섬 전체 지도가 표시됩니다. 등록한 맛집에서 **장소 검색** 후 정확한 결과를 선택하거나 **지도에서 지정**으로 지점을 클릭하면 번호 핀과 함께 위치가 자동 저장됩니다. 이름·주소·섬 변경 시 기존 좌표는 해제되므로 위치를 다시 지정하세요. 위치 검색은 OpenStreetMap Nominatim을 사용합니다.

### 마트
맛집 아래 **마트** 메뉴에서 슈퍼마켓·코스트코 등 장보기 장소를 섬별로 등록할 수 있습니다. 맛집과 구분하여 이름·주소·구매할 품목·링크·메모를 저장하며, 장소 검색과 지도 위치 지정, 자동 저장을 동일하게 지원합니다.

### 일정 대표 이미지
일정 카드가 화면에 보이면 장소명으로 Wikipedia의 대표 이미지를 자동 조회합니다. 사진을 누르면 해당 장소의 소개 문서가 새 탭에서 열리며, 사진 아래 출처·라이선스 링크를 제공합니다. 하와이 주요 관광지의 한글 명칭을 지원하고, 제목이 일치하지 않거나 이미지가 없으면 사진을 표시하지 않습니다. 검색은 장소명만 외부 서비스에 전달하며, 결과는 현재 세션 메모리에만 보관합니다. API 장애 시 기존 일정은 그대로 사용할 수 있습니다.

일정 수정창의 **대표 이미지 URL**에 HTTPS 사진 파일 주소를 입력하면 자동 사진보다 우선 표시됩니다. **사진 클릭 시 열릴 소개 링크**를 지정할 수 있고, 비워두면 기존 참고 링크를 사용합니다. 이미지 URL을 비우면 자동 검색으로 돌아갑니다. 외부 사이트가 이미지 직접 표시를 차단하는 경우에는 사진을 불러올 수 없습니다.

### 서버 저장 실패 시 입력 보호
서버 전송 전에 현재 변경과 기준 저장본을 이 브라우저의 별도 IndexedDB에 암호화해 보관합니다. 서버 전송이 실패하면 **이 기기에 암호화 저장됨 · 서버 전송 대기**로 표시하며, 같은 브라우저에서 서버 로그인 후 미전송 입력을 복구합니다. 서버 저장 성공 후 복구본을 정리합니다. 기기 보관은 다른 PC에 동기화된 상태가 아니며, 브라우저 데이터 삭제 시 없어질 수 있습니다.
